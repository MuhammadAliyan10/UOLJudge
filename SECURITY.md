# Security Policy

## Supported Versions

Only the latest major version of UOLJudge is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| 4.x     | :x:                |
| < 4.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in UOLJudge, please follow these steps:

1.  **Do NOT open a public issue.**
2.  Email the details of the vulnerability to **security@uoljudge.com** (or the project maintainer directly).
3.  Include as much information as possible:
    - Type of vulnerability (e.g., XSS, SQL Injection, RCE).
    - Steps to reproduce.
    - Affected components.
    - Potential impact.

## Response Timeline

- **Acknowledgment:** We will acknowledge your report within 48 hours.
- **Assessment:** We will investigate the issue and determine its severity within 1 week.
- **Fix:** If confirmed, we will release a patch as soon as possible.

## Disclosure Policy

We ask that you give us a reasonable amount of time to fix the issue before disclosing it to the public. We will coordinate the public disclosure with you.

Thank you for helping keep UOLJudge secure!
